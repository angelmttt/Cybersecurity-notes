etc/group aparecen los identificadores del grupo
etc/passwd donde se definen los usuarios existentes y directorios personales 
etc/shell tipos de shell existentes

$PATH variable de entorno que contiene varias rutas que aparece con un orden de prioridad al realizar una búsqueda
$HOME variable de entorno que dice cual es el directorio personal
$SHELL variable de entorno que dice que shell estas usando

| pipearlo tratar el output y aplicarle un filtro
grep {-n (número de linea)} filtrar por lo que quieras

which para validar si existe // si no existe which command -v

pwd ruta actual donde te situas
ls (-l te lista de forma más detallada) listar el contenido de la ruta que quieras

cd cambiar de directorio
	..  vuelves para atrás de donde te situas
	/home/angelmt/descargas ruta específica
	/ directorio raíz
	 (nada) directorio personal del usuario
